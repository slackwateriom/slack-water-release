# Slack Water

Early test version of an Android fishing app for the Isle of Man.

**This version has not been fully tested. Bugs could cause data loss, so save a backup regularly.**

Tide times are estimates, not official tables. For planning only, not for navigation. Always check conditions yourself.

Download the latest APK from [Releases](https://github.com/slackwateriom/slack-water-release/releases).
